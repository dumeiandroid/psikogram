⚙️ Konfigurasi Tampilan Dashboard

Atur grup dan card mana yang ingin ditampilkan. enabled: false untuk menyembunyikan.

📖 Panduan:
• "enabled": true → tampilkan grup/card
• "enabled": false → sembunyikan grup/card
• "displayName": "Nama Baru" → ubah nama grup
• "icon": "🚀" → ubah icon
• Card dengan "enabled": false akan disembunyikan dari grupnya
